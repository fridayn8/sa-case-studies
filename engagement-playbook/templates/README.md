# Engagement Templates

Blank, copy-and-fill templates for the documents an engagement produces. Each one has a short
**how to use** section, the blank template and one **mini-example** taken from
[Case 01](../../case-01-example-corp/README.md).

| Stage | Template | Produces |
|-------|----------|----------|
| [0 Pitch](../00-pitch.md) | [Lead qualification checklist](lead-qualification-checklist.md) | Go/no-go with reasons |
| [1 Discovery](../01-discovery.md) | [Discovery questionnaire](discovery-questionnaire.md) | Interview notes, evidence |
| [1 Discovery](../01-discovery.md) | [Stakeholder map](stakeholder-map.md) | Interests, fears, conflicts |
| [3 Options](../03-options-and-decisions.md) | [Options decision matrix](options-decision-matrix.md) | Weighted comparison, PoC record |
| [5 Proposal](../05-proposal-and-commercial.md) | [Solution proposal](solution-proposal-template.md) | The document the client approves |
| [5 Proposal](../05-proposal-and-commercial.md) | [SOW outline](sow-outline-template.md) | Scope, acceptance, change control |
| [1](../01-discovery.md)–[9](../09-review.md) | [Risk register](risk-register-template.md) | Risks with owners |
| [5](../05-proposal-and-commercial.md) and [9](../09-review.md) | [Estimation worksheet](estimation-worksheet.md) | Estimate, actuals, calibration |
| [6 Build](../06-build-oversight.md) | [Change request impact analysis](change-request-impact-analysis.md) | Scope change decision |
| [7 Go-live](../07-test-and-go-live.md) | [Cutover plan and Go/No-Go](cutover-plan-template.md) | Steps, checkpoints, rollback |

## Generic design templates

ADR, requirements, HLD, LLD, threat model, runbook, postmortem and operational change request
templates are in the [`sa-handbook`](https://github.com/fridayn8/sa-handbook/tree/main/templates)
repository; they are linked from the stage files and not duplicated here.
